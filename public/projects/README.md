# Project Images

Put screenshots for each portfolio project in the matching folder below.

After adding an image, open `src/data/projects.ts` and add the public path to that project's `screenshots` array.

Example:

```ts
screenshots: [
  "/projects/running-prediction/model-results.png",
  "/projects/running-prediction/notebook-preview.png",
],
```

Folders:

- `emotion-recognition-ppg`
- `fingerprint-authentication-system`
- `defect-prediction-risk-modeling-tool`
- `distributed-cnn-training`
- `running-prediction`
- `real-time-facial-hand-recognition`
- `pixelmp3`
- `christmas-tree-database`
- `inventory-management-system`
